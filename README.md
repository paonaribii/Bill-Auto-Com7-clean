# Bill Auto: ระบบตรวจบิลอัตโนมัติ (K2 / ITOS / iTEC)

## เรื่องมันเริ่มจากอะไร

งานตรวจบิลสินเชื่อผ่อนมือถือแต่ละวัน ต้องเอาข้อมูลจาก 3 ระบบมาเทียบกัน:

- **K2**: ระบบใบสั่งซื้อ (PO) และสถานะการอนุมัติ
- **ITOS**: ระบบใบคำขอสินเชื่อ
- **iTEC**: โปรแกรมเปิดบิลขายของหน้าร้าน เป็นโปรแกรม desktop ไม่ใช่เว็บ

เดิมทีมต้อง export ไฟล์จากทุกระบบ วางลง Google Sheets แล้วไล่ดูว่า
บิลไหนชื่อลูกค้าไม่ตรง ราคาผิด เปิดบิลผิดบริษัท หรือยังไม่ได้อนุมัติ งานนี้ใช้เวลาเยอะ พลาดง่าย
และชีทที่ใส่สูตรไว้เยอะๆ ก็ช้าจนเปิดแทบไม่ขึ้น

## ระบบนี้ทำอะไร

รันคำสั่งเดียว ระบบจะทำงานให้ตั้งแต่ต้นจนจบ:

1. **ดึงข้อมูลเอง**: login เข้า K2 กับ ITOS ด้วย Playwright, ควบคุมโปรแกรม iTEC บน Windows
   ด้วย pywinauto และดึงข้อมูล iTEC MIS ผ่าน API
2. **เทียบข้อมูลด้วย Pandas**: เอาสูตรที่เคยอยู่ใน Google Sheets มาเขียนใหม่เป็น Python
   เพื่อจับคู่บิลข้าม 3 ระบบ และเช็กชื่อลูกค้า ราคา รหัสลูกค้า สาขา และชื่อบริษัท
3. **แยกผลออกเป็นกลุ่ม**: บิลถูกต้อง รออนุมัติ ต้องแก้ไข หรือหน้าร้านเปิดบิลผิด
   แล้วเขียนลงชีทที่แต่ละทีมใช้งาน
4. **เก็บประวัติ**: ก่อนเขียนทับข้อมูลวันนี้ จะเก็บผลของเมื่อวานไว้ก่อน เพื่อหาว่า
   "วันนี้มีบิลผิดใหม่อะไรเพิ่ม" แล้วส่งต่อไปบันทึกความผิดโดยไม่ซ้ำของเดิม
5. **เช็กสถานะจริง**: เปิด K2/ITOS ตรวจสถานะบิลที่ยังค้างอยู่

```
K2 ─┐
ITOS ├─► ดึงข้อมูลดิบ ─► Pandas จับคู่ + ตรวจ ─► แยกกลุ่มบิล ─► Google Sheets ของแต่ละทีม
iTEC ┘                                                     └─► บันทึกบิลผิดใหม่ประจำวัน
```

## สิ่งที่ได้เรียนรู้ / จุดที่ภูมิใจ

- **ย้ายการคำนวณออกจาก Google Sheets มาไว้ใน Python** ชีทที่ใส่สูตรเยอะจนช้าและชอบตอบ 503
  เปลี่ยนเป็นคำนวณใน Pandas แล้วเขียนแค่ผลลัพธ์กลับไป ทำให้เร็วขึ้นและผลคงที่กว่าเดิมมาก
- **ควบคุมโปรแกรม desktop เก่า** iTEC ไม่มี API ให้เรียก ต้องใช้ pywinauto กดหน้าจอ และต้องจัดการ
  เองเวลาโปรแกรมค้าง (ตั้ง timeout ด้วย thread แยก เพราะ pywinauto ไม่มีให้)
- **หาวิธีที่ง่ายกว่า** เช่น ตอนต้องการชื่อลูกค้าของบิล 21,000+ ใบ แทนที่จะเปิดเบราว์เซอร์ค้นทีละใบ
  (ลองแล้วช้ามาก) พบว่าชื่ออยู่ในช่อง Comment ของ iTEC ที่ดึงมาทุกวันอยู่แล้ว เลยใช้ text parsing แทน
- **เขียนให้พังอย่างปลอดภัย** pipeline แบ่งเป็นสเตจ ถ้าสเตจไหนพังจะหยุดทันที
  จะได้ไม่เอาข้อมูลที่ยังไม่ครบไปเขียนทับชีทปลายทาง ชีทสะสมเป็นแบบเพิ่มต่อท้ายอย่างเดียว ไม่ลบของเดิม

## เทคโนโลยีที่ใช้

Python · Pandas · Playwright · pywinauto · gspread (Google Sheets API) · python-dotenv

## โครงสร้างโปรเจกต์

```
main_run_full_pipeline.py   จุดรันเดียว เรียกทุกสเตจตามลำดับ
config.py                   อ่านค่าทั้งหมดจาก .env
sheets_client.py            ตัวช่วยอ่าน/เขียน Google Sheets (มี retry)
clean.py, date_utils.py     ทำความสะอาดข้อมูล และจัดการวันที่ พ.ศ./ค.ศ.
clean_flow/                 สเตจ 0: ดึงข้อมูลดิบจาก K2, ITOS, iTEC, iTEC MIS
process_flow/               สเตจ 1-6: จับคู่ แยกกลุ่ม และกระจายผลไปชีทปลายทาง
  cal.py                    logic การจับคู่ที่ย้ายมาจากสูตร Google Sheets
```

## วิธีรัน

```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env              # กรอก URL, user/password และ Sheet ID ของแต่ละระบบ

python main_run_full_pipeline.py                # รันทั้งหมด
python main_run_full_pipeline.py --skip-fetch   # ข้ามการดึงข้อมูลดิบ (ถ้าดึงไปแล้ววันนี้)
python main_run_full_pipeline.py --skip-check   # ข้ามการเช็กสถานะผ่านเบราว์เซอร์
```

> ส่วนที่ควบคุมโปรแกรม iTEC ต้องรันบน Windows

## หมายเหตุ

รหัสผ่าน และข้อมูลลูกค้าออกหมดแล้ว ค่าทั้งหมดต้องตั้งเองใน `.env`
