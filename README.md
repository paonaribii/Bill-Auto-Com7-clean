# Bill Auto: ระบบตรวจบิลขายผ่อนมือถืออัตโนมัติ

> **สรุปสั้นๆ:** โปรแกรมที่เปิดระบบของบริษัท 3 ระบบแทนคน ดึงข้อมูลบิลออกมา เทียบกันว่าตรงกันไหม
> แล้วทำรายการ "บิลที่ผิด" ส่งให้ทีมที่ต้องแก้ไข ทุกขั้นตอนเสร็จได้ด้วยคำสั่งเดียว
>
> **ผลลัพธ์:** งานตรวจบิลประจำวันจากเดิม **ประมาณ 6 ชั่วโมง เหลือประมาณ 30 นาที**

## ที่มา

บริษัทขายมือถือแบบผ่อนผ่านสาขาทั่วประเทศ ทุกครั้งที่ลูกค้าผ่อนเครื่อง 1 เครื่อง
ข้อมูลของการขายครั้งนั้นจะไปอยู่ใน **3 ระบบที่แยกกัน**:

| ระบบ | เก็บข้อมูลอะไร |
|---|---|
| **K2** | ใบสั่งซื้อ และสถานะว่าอนุมัติแล้วหรือยัง |
| **ITOS** | ใบสมัครขอผ่อนของลูกค้า |
| **iTEC** | บิลขายที่พนักงานหน้าร้านเปิด (เป็นโปรแกรมเก่าบน Windows ไม่ใช่เว็บ) |

ทั้ง 3 ระบบต้องมีข้อมูลตรงกัน เช่น ชื่อลูกค้า ราคา สาขา และบริษัทที่ออกบิล
ถ้าไม่ตรงกัน บิลนั้นจะมีปัญหาทางบัญชี และต้องให้สาขาแก้ไข

**เดิม** พนักงานต้อง export ไฟล์จากทั้ง 3 ระบบทุกวัน เอามาวางใน Google Sheets
แล้วไล่ดูทีละบิลว่าใบไหนผิด งานนี้ทั้งกินเวลาและพลาดง่าย และพอข้อมูลเยอะขึ้น
ชีทที่ใส่สูตรไว้มากๆ ก็ช้าจนแทบเปิดไม่ขึ้น

## โปรแกรมนี้ทำอะไรแทนคน

```
 ① เปิดระบบ K2, ITOS, iTEC แล้วดึงข้อมูลบิลออกมาเอง
            │
            ▼
 ② จับคู่บิลเดียวกันจากทั้ง 3 ระบบ แล้วตรวจทีละช่องว่าตรงกันไหม
            │
            ▼
 ③ แยกบิลออกเป็นกลุ่ม: ถูกต้อง / รออนุมัติ / ต้องแก้ไข / สาขาเปิดบิลผิด
            │
            ▼
 ④ เขียนผลลง Google Sheets ของทีมที่ต้องใช้แต่ละกลุ่ม
            │
            ▼
 ⑤ เทียบกับผลของเมื่อวาน เพื่อหาว่า "วันนี้มีบิลผิดใหม่อะไรบ้าง" แล้วจดลงบันทึกความผิดพลาด
```

พนักงานแค่สั่งรันครั้งเดียว แล้วรอเปิดดูผลในชีท จากงานที่เคยใช้เวลาประมาณ 6 ชั่วโมงต่อวัน
เหลือประมาณ 30 นาที

## ความท้าทาย และวิธีแก้

**1. โปรแกรมเก่าที่ไม่มีช่องทางให้ดึงข้อมูล**
iTEC เป็นโปรแกรมบน Windows ที่ไม่มีช่องทางให้โปรแกรมอื่นดึงข้อมูลได้ตรงๆ
เลยเขียนโปรแกรมให้ "กดปุ่มและกรอกช่องบนหน้าจอแทนคน" (ใช้ pywinauto)
และเพราะบางครั้งโปรแกรมค้างเอง ก็เลยเพิ่มตัวจับเวลาไว้ ถ้าค้างนานเกินไปจะตัดจบแล้วลองใหม่

**2. Google Sheets ช้าเกินไป**
เดิมการคำนวณทั้งหมดอยู่ในสูตรของชีท จนชีทช้าและบางครั้งก็ error
เลยย้ายการคำนวณทั้งหมดมาทำใน Python (ใช้ Pandas) แล้วเขียนกลับไปที่ชีทแค่ผลลัพธ์
ทำให้เร็วขึ้นและได้ผลเหมือนกันทุกครั้ง

**3. หาวิธีที่ง่ายกว่าเดิม**
เคยต้องหาชื่อลูกค้าของบิลกว่า 21,000 ใบ วิธีแรกคือเปิดเว็บค้นทีละใบ แต่ช้ามาก
ภายหลังพบว่าชื่อลูกค้ามีอยู่แล้วในช่องหมายเหตุของ iTEC ที่ดึงมาทุกวัน
เลยเปลี่ยนมาแยกชื่อจากข้อความนั้นแทน ทำให้ไม่ต้องเปิดเว็บเลย

**4. ถ้าพลาด ต้องไม่ทำให้ข้อมูลเสียหาย**
งานแบ่งเป็นขั้นตอนย่อย ถ้าขั้นไหนพัง โปรแกรมจะหยุดทันที ไม่เอาข้อมูลที่ยังไม่ครบ
ไปเขียนทับชีทของทีมอื่น ส่วนชีทที่เป็นประวัติจะเพิ่มต่อท้ายอย่างเดียว ไม่ลบของเดิม

## สำหรับนักพัฒนา

**เทคโนโลยีที่ใช้:** Python · Pandas · Playwright (ควบคุมเว็บ) · pywinauto (ควบคุมโปรแกรม Windows) ·
gspread (Google Sheets API)

### โครงสร้างโปรเจกต์

```
main_run_full_pipeline.py   จุดเริ่ม เรียกทุกขั้นตอนตามลำดับ
config.py                   อ่านค่าตั้งค่าทั้งหมดจากไฟล์ .env
sheets_client.py            อ่าน/เขียน Google Sheets (ลองใหม่อัตโนมัติถ้า error)
clean.py, date_utils.py     ทำความสะอาดข้อมูล และแปลงวันที่ พ.ศ./ค.ศ.
clean_flow/                 ขั้นตอนดึงข้อมูลจาก K2, ITOS, iTEC
process_flow/               ขั้นตอนจับคู่ ตรวจ แยกกลุ่ม และเขียนผล
  cal.py                    กฎการจับคู่บิล (ย้ายมาจากสูตรใน Google Sheets)
```

### วิธีรัน

```bash
pip install -r requirements.txt
playwright install chromium
cp .env.example .env              # กรอก URL, user/password และ Sheet ID ของแต่ละระบบ

python main_run_full_pipeline.py                # รันทั้งหมด
python main_run_full_pipeline.py --skip-fetch   # ข้ามการดึงข้อมูล (ถ้าดึงไปแล้ววันนี้)
python main_run_full_pipeline.py --skip-check   # ข้ามขั้นเช็กสถานะสุดท้าย
```

ส่วนที่ควบคุม iTEC ต้องรันบน Windows
